      边界站操作手册

      先点火，再让工厂自己运转。

      顶部“任务”开关控制悬浮任务栏。“入门”追踪当前教学，“主线”统一显示阶段工程与材料缺口。可最小化、关闭或换边，不占生产区空间；定位设备后自动最小化。材料图鉴可查看规划路径，不解锁生产能力。

      重新练习入门 · 不覆盖正式存档 ↗
      1. 从两次实验开始。 两台熔炼釜已装好铁矿 / 铜矿与煤炭，点击“实验一批”。左侧原料会自动采集，无需反复点击。
      2. 重启控制总线。 凑齐 6 生铁、4 精炼铜，并发现两条反应，在任务栏“主线”中提交工程。随后可打开每台设备的连续生产。
      3. 调配进料与温度。 煤炭和焦炭都具有还原剂标签，焦炭能减少杂质损失。实际发现的反应可在笔记里选择目标设备后装载。先停止该设备连续生产并等本批完成。设备卡片的“调整进料与参数”可以随时展开。注意按线索切换温度。
      4. 照顾电力、热量和仓储。 每批预付能量与原料；不足就等待。90 废热触发停机，低于 65 恢复。水冷耗水，尾气可回收，也可释放。
      5. 混炼两个有效反应。 “双路混炼”升级后，铁矿＋铜矿＋还原剂可同批产铁和铜；两条反应的还原剂都会扣除。单纯增加无关材料不会增产。
      6. 完成首章。 钢材 → 循环工坊 → 硅与电路 / 炉渣再生 → 虚境稳定剂 → 第一枚现实锚点。随机只影响额外收率，基础产出有保障。

      v0.3 是游戏规则原型；材料数值不代表现实化学。存档留在本浏览器中，建议定期导出。暂停时离线也不生产；关闭自动运行会完成当前批次后停止。
