# 《熔炉》开发方向与阶段路线图

更新：2026-08-27。状态：v0.3 首章原型已实现。

## 1. 当前方向

**用有限的反应设备，建立会持续增长、又需要照顾资源循环的工业网络。**

玩家的主要操作应从“亲自实验每一批”，逐步变成“观察瓶颈、改造网络、决定下一项工程”。配方发现是通向自动化的学习过程。

这里把用户提出的三个参照转化成设计目标，而不尝试同时复制三款完整游戏：

| 参照方向 | 本作吸收的体验 | 首章实现 |
|---|---|---|
| 《缺氧》 | 生产相互影响；副产物、热量需要进入回路 | 废热、耗水散热、尾气与炉渣回收、仓满停产 |
| 《戴森球计划》 | 从短链扩展成长链，通过自动化推动工程目标 | 自动采集、连续生产、钢—硅—电路—锚点链 |
| 增量游戏 | 持续产出、阶段解锁、升级与回访收益 | 设施改造、工程、离线结算 |

视觉方向：精密工业与神秘学。深灰设备、黄铜标记、绿色运行反馈、紫色虚境信息。

## 2. 首阶段的核心

自动采集 → 装载材料 / 调整温度 → 观察反应候选 → 实验并发现 → 连续生产 → 处理能量与副产物瓶颈 → 投入工程 / 升级 → 新材料与新设备。

短目标：第一次产出铁、铜。中目标：让产线持续生产，并建立回收工坊。首章目标：制造并提交第一枚现实锚点。

## 3.规则决策

### D01：有限设备，不按填槽数量赠送并行

- 初始两台熔炼釜；工程依次增加一台循环工坊、一台虚境调和釜，首章最多四台。
- 四个进料选择表示仓库供料通道，不是四份免费库存。每批按实际反应角色扣除数量。
- 未升级时，不同候选按批轮换，避免总是选中列表第一项。
- “双路混炼”后，至多两条不同且都有效的反应同批运行。
- 例如铁矿＋铜矿＋煤炭：炼铁消耗两份煤炭，炼铜消耗一份，总共三份。库存不足时只执行可负担的路线。
- 同批共享加热，能耗为各路线总能耗的 82%；原料不会打折。无关进料不增产。
- 已发现路线可以锁定生产；锁定时只有一路，便于专产，但牺牲混炼节能。

这一规则接近新增原始策划中“多条真实反应共用一釜”的意图，取代旧仓库里互相矛盾的“≥3 材料 / 输入数量即并行度”规则。

### D02：物质身份保证来源，标签负责角色替代

- 不用任意标签凭空生成物质。含铁来源仍需铁矿，不能只凭“金属”标签变出铜。
- 首章实现“还原剂”标签槽：煤炭和焦炭可替换；焦炭提高额外收率并降低杂质导致的能耗、废热。
- 反应族和产物仍由数据明确编写。后续增加酸碱、催化、气相等角色前，应先补充数值与物质来源审核。
- 当前不是通用化学模拟器；配比和电热单位是游戏抽象。

### D03：随机影响收率，不让基础工业依赖连续抽奖

- 有效反应保证最低目标产量；部分反应有一次额外产出的随机机会。
- 每条实际完成的反应积累熟练度，提高额外产出概率；基础产物与副产物不相互顶替。
- 副产物在有定义的反应中固定产出，因此玩家能规划回收能力。
- 未知反应只显示反应族、线索和当下额外收率，成功完成后揭示公式及快捷装载。
- 这是 v0.3 的设计取舍，不是对原始“完全随机池”方案的最终否定。更强的随机性应优先放在可选择的虚境研究支路，而不是关键基础物资上。

### D04：压力可恢复

- 设备开工前检查全部原料、电力和最坏情况下的产物空间。
- 能量与原料预付；输出空间跨设备预留。仓满时不继续投入，也不静默丢弃产物。
- 废热达到 90 触发热保护，降至 65 以下恢复。被动供电与自然散热不消耗资源。
- 水冷按等级耗水，无水退回自然散热；停机不毁坏设备。
- 尾气可以进入固碳工艺，也可以安全排出而损失回收价值。首章没有单独的污染、生存或生态惩罚模型。

### D05：增量来自解放操作与增加选择

- 自动采集从开局就有；第一项工程解锁连续生产。
- 改造提升采集、电力、散热、混炼与储量，而非只给一串无决策价值的倍数。
- 项目消耗库存，并且只能完成一次；完成锚点后仍可继续优化，不强制清空产线。
- 当前不承诺转生系统。只有未来跨区域扩展需要长期结构性成长时再评估。

### D06：在线与离线用同一套模拟规则

- 固定 0.25 秒模拟步长，种子随机数，在线帧率不改变结果。
- 保存正在处理的批次、剩余时间、已扣的材料、自动化开关及随机数状态。
- 离线最多结算 30 分钟，仍受仓满、原料、电力、热保护影响。
- 暂停时离线也不生产；关闭连续生产只是不再开新批，当前批次照常完成。
- 浏览器本机保存，每十秒及关键操作保存一次；支持 JSON 导出、导入和损坏存档恢复副本。
- 存档用于便利，不是反作弊。暂不支持多设备云同步或多个浏览器标签同时游玩同一存档。

## 4. v0.3 实际交付范围

- 18 种资源、11 条反应、2→4 台设备、5 类设施改造、4 项一次性工程。
- 自动采集、手动批次、连续生产、温度/超频、已发现配方锁定、铁铜共炼快捷配置。
- 炉渣→胶结料；尾气＋水→碳质燃料；电力与废热软约束。
- 首章终点：钢＋电路＋虚境稳定剂＋胶结料，在工坊装配现实锚点，再提交工程。
- 完整状态与模拟模块独立于界面；无需第三方运行依赖。
- 中文页面、实验笔记、工程需求条、运行原因提示、日志、操作手册、本机存档。

## 5. 后续里程碑与验收关卡

以下是按依赖排序的开发路线，不是未经评估的工期承诺。每个阶段先达到验收关卡再扩内容。

| 阶段 | 核心问题 | 工作范围 | 验收关卡 |
|---|---|---|---|
| **M0 / v0.3 首章** | 三种机制能否形成一个闭环？ | 本文已实现范围；边界与通关测试；浏览器验证 | 从新存档只靠真实资源通关，无负库存、无永久死局，能恢复在制批次 |
| **M1 / v0.4 可读与平衡** | 玩家能否理解为何停机、该做什么？ | 最近产率与净流量、消费/供给预测、生产队列、原料最低保留量、快捷配方选择目标机、试玩反馈 | 至少 3 位首次玩家；不口头指导即可完成首项工程；记录首发现时间、卡点与误操作；混炼/专产都有可说明的收益 |
| **M2 / v0.5 工业网络** | 多釜调度是否有策略深度？ | 节点式产线图、显式连接与中间缓冲、生产优先级、目标库存、跨工位模板 | 至少两种有效布局；稳定运行十分钟；瓶颈能在图上定位；所有回路遵守真实库存 |
| **M3 / v0.6 资源环境** | 环境反馈能否带来改造需求？ | 热交换与余热利用、液/气储量、更多回收支路、物质来源审计、渐进信息展示 | 不新增无用废料；至少一条能量/物料回收路线胜过排放；断水断电可恢复 |
| **M4 / v0.7 虚境与章节** | 不确定性在何处最好玩？ | 稳定生产/高风险实验双模式、可读概率池、研究保底、第二片区域与长期工程 | 玩家明确理解风险与收益；基础生产不被随机事故长期中断；出现多条可行中期路线 |
| **M5 / 发布准备** | 能否稳定扩内容与保存进度？ | 内容工具、历史数据迁移、存档迁移、多标签页保护、无障碍与性能、分发与许可检查 | 升级不丢存档；自动测试/通关回归；干净环境可运行；收到明确授权再发布 |

### 下一轮

**v0.3.2 进度**：根据试玩反馈，入门和阶段目标已合并为悬浮任务栏；独立图鉴已整理到 104 种材料 / 94 条路线，只有原有 18 种材料 / 11 条反应参与生产。新增材料与路径先作为内容规划，不等于 M2–M4 已完成。

**v0.3.1 进度**：七步自适应入门、实际操作定位、缺料/缺电/过热/仓满恢复建议、指定目标设备装载与独立练习场已实现。这是 M1 的部分交付；净流量、目标库存/排程和首次玩家验收尚未完成。

1. **产线反馈**：净产率、消耗速率、原料不足的可视化；现在只有采集速率与批次预付信息。
2. **目标库存和排程**：让一台工坊轮换回收/电路，不要求玩家每批手动切换；避免产线把终局要用的钢或铜吃光。
3. **真实试玩**：验证本章的认知负担和时长，再决定完整材料库应如何逐章引入。
