# 悬浮任务系统与材料图鉴 / v0.3.2

### 悬浮任务栏

- 顶部“任务”开关控制非模态悬浮窗口，不参与生产布局；关闭后右下角仍有入口。
- “入门”追踪七课，“主线”显示四项工程、材料缺口、发现要求和提交按钮。原来的顶部引导块和右侧独立工程卡已移除。
- 支持最小化、左右换边、关闭与 Escape；任务说明和进度清单默认折叠。
- 定位设备时自动最小化，避免挡住操作。定位到工程时展开主线页。
- 开关、页签、最小化与停靠侧保存在原存档的引导设置中。旧存档缺字段时补默认值。
- 工程仍真实扣料。关闭任务栏不暂停生产，也不停止记录引导进度。

### 材料与工艺图鉴

| 内容 | 数量 | 接入边界 |
|---|---:|---|
| 材料条目 | 104 | 18 种在当前生产规则中；86 种只在图鉴中 |
| 路线条目 | 94 | 11 条直接映射当前规则；83 条为规划工艺 |
| 产业链分类 | 6 | 金属与合金、气体与化工、硅与电子、能源与储能、建材与循环、虚境与终局 |

- 整理历史 73 种材料、59 条路径；新增 26 种蓝图材料与 24 条规划路径，并合并当前原型独有的水、玻璃、胶结料、电路和锚点条目。
- 支持中文/英文 ID/标签搜索、层级/产业链/接入状态筛选、材料详情、来源与下游用途、关联材料跳转和返回。
- 来源树展示一条示例路径，可从具体路线切换追溯。优先当前规则，其次较短规划路径；角色替代只选一种示例，回路/深度/节点数均有限制。
- 当前尚未发现的配方默认仍只给线索；玩家主动勾选预览后可看全式，但不登记发现、不解锁科技。
- 规划配方只定义投入材料、主产物、副产物/联产品、设备概念和用途。数量、能耗、时间、概率与设备条件尚未平衡，不可投入当前生产。旧配方权重没有转换成概率或产量。

以上是游戏内容与物料关系抽象。除注明的来源修订外，没有对所有历史工艺逐项做现实化学审计；更不表示化学计量、热力学或操作条件已验证。需在接入生产前再完成物料身份、计量、损耗和玩法价值审核。

## 代码边界

- `demo/data.js`：当前可玩规则唯一来源，本轮没有添加新的库存或可执行反应。
- `demo/catalog-plans.js`：独立、可维护的材料与路径蓝图。历史数据已整理为快照，不在运行时读取 `src/` 或 `web/`。
- `demo/catalog-data.js`：合并蓝图与当前规则、搜索/关系索引、来源可达性和有界来源树。
- `demo/catalog-ui.js`：图鉴交互。不能调用开工、项目解锁或库存写入。
- `demo/app.js`：悬浮任务与视图适配；`guidance.js` 原有进度逻辑保留。
